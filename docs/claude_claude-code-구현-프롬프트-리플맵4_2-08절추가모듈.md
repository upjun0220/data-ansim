## 목적과 범위

공용 충전 거점의 부하 완화 가능성을 분석해 주민의 전력 이용 안정성(안전), 자가 충전이 어려운 시민의 접근성(형평성), 합리적 설비 투자(경제성)를 지원한다. CATE는 상권 파급효과의 보조 지표이며 저CATE 지역을 투자 대상에서 배제하지 않는다.

현재 구현은 **과거 이력에 대한 1일 독립 배치 시뮬레이션**이다. 정전 예방, 취약계층 수혜, 변압기 교체비 절감, 전역 최적 ESS 용량을 입증하지 않는다. 차량 충전 수요를 시간 이동하는 최적화와 생애주기 경제성은 후속 범위다.

## 3. `load_forecast.py` — 8-A

Python 함수:

```python
forecast_load(load_df, target_date, region, W=4, holidays=None)
backtest_forecast(load_df, region, n_weeks_holdout=8, W=4, holidays=None, end_date=None)
```

수식: `L_forecast(r,d,h) = median(L_observed(r,d−7w일,h), w=1..4)`.
`d`는 날짜, `h`는 시각이다. 7w시간을 빼는 식이 아니다.

- 대상일 이전 같은 요일·시간대 4개 관측을 사용한다. 하나라도 없으면 실패로 남긴다.
- `holidays={날짜: 유형}`을 입력한 경우 대상 휴일과 같은 유형의 과거 휴일 4개를 사용한다. 부족하면 실패한다. 미입력은 **공휴일 미보정**이며 공식 달력을 임의로 만들지 않는다.
- 기본 백테스트: ESS 평가 시작일 이전 8주(56일). 각 검증일 예측에도 그날 이전 이력만 사용한다. 따라서 최소 12주 이력이 필요하다.
- 비교 모델: 전날 같은 시각 부하(persistence). 두 모델 모두 평가 가능한 동일 관측 셀에서 MAE를 계산한다.
- 산출: 전체 MAE, 전날값 MAE, 평균 오차(실측−예측), 증가일 평균 오차, 실제 일별 피크 시각 MAE, 검증일수·셀수·제외일수, 달력 적용 상태.
- 증가일은 실제 하루 충전량이 이전 4주 동일 요일 하루 충전량 중앙값보다 큰 날이다. 성장의 인과적 판정이 아니다.
- 급격한 우상향 추세에서 과소 예측할 수 있다. 기본 신뢰 조건은 검증일 28일 이상, 계절 MAE ≤ 전날값 MAE, |평균 오차| ≤ 교정기간 평균 부하의 10%다. 프로젝트 기준이며 공인 안전기준이 아니다.
- **예측 실패 시 실측으로 대체하지 않는다.** 예측 행은 `method=unavailable, plan_feasible=False`, 실측을 아는 oracle은 별도 비교 행이다.

## 4. `ess_optimizer.py` — 8-B

### 추가 부하·사전 교정

`ΔL(r,h) = N_new × P_charger × u(h)`, N_new=0/2/3/5, P_charger 기본 7kW.

`u(h)`는 0~1 가정이다. 신뢰 가능한 사전 CAN 세션의 시간별 겹침을 최대값 1로 정규화하고 기본 배율 0.5를 곱한다. 이는 충전기 대수를 분모로 가진 실제 이용률이 아니다. 개별 차량 판정 불가·표본 부족이면 설정의 상대 시간대 모양을 사용하고 출처를 기록한다. CAN 사용 세션은 사전 기준일 전에 종료한 것만 쓴다.

평가 시작 전 28일의 완전한 일별 실측 곡선으로 대상·상한·용량을 고정한다.
`P_target = max(교정기간 기존 충전 부하) × multiplier`, multiplier=1.1/1.2/1.3.
관측 최대 충전 부하는 변압기의 전체 부하나 정격이 아니며 배수는 정책 시나리오다.

### 운전 정책과 선형계획

이번 구현은 **목표 초과분만 방전하고 비첨두 재충전을 최적화**하는 제한된 피크쉐이빙이다. 자유로운 가격차익 거래·충전기 수요 시간 이동은 구현 범위에 없다.

수식(Δt=1h, e는 저장 에너지 kWh):

```text
min Σ SMP(h) · (c(h) − d(h)) · Δt
0 ≤ L_forecast(h) + ΔL(h) + c(h) − d(h) ≤ P_target
0 ≤ c(h), d(h) ≤ P_ess
e(h+1) = e(h) + η_c·c(h)·Δt − d(h)·Δt/η_d
SOC_min·E_ess ≤ e(h) ≤ SOC_max·E_ess
 e(0) = SOC_initial·E_ess, e(24) = e(0)
d(h) = [L_forecast(h) + ΔL(h) − P_target]⁺
c(h) = 0 if L_forecast(h) + ΔL(h) > P_target
```

초과 시 고정 방전·비초과 시 충전 제한으로 동시 충방전을 금지한다. 순부하 하한 0으로 전력 판매를 금지한다. 에너지 상태를 사용해 ESS 0kWh도 0으로 나누지 않고 처리한다.

가정 기본값: η_c=η_d=0.95, SOC_min=0.1, SOC_max=0.9, SOC_initial=0.5. 실제 장치 사양은 확인 전이다.

`scipy.optimize.linprog(method='highs')`를 사용한다. SMP 없음은 재충전 순부하 피크 최소화로 전환한다. scipy 미설치·LP 실패는 그리디로 전환하되, 상한·역송·출력·SOC·초기/종단 잔량·동시 충방전을 사후 검증한다. 실패한 그리디를 실행 가능한 계획이나 최적해로 처리하지 않는다.

### 후보 용량 검증

당일 실측으로 용량을 고르고 같은 날 성과를 평가하지 않는다. 평가 이전 교정 부하+가정 증설 부하에 대해 검증한다.

```text
P_ref = max_{d,h} [L_calibration(d,h)+ΔL(h)−P_target]⁺
E_ref = max_d Σ_h [L_calibration(d,h)+ΔL(h)−P_target]⁺·Δt / {η_d·(SOC_max−SOC_min)}
후보(kW,kWh): (0,0),(7,20),(14,40),(28,80),(56,160),(112,320),(224,640)
```

E_ref는 방전 구간 내 재충전이 없다는 가정의 참고값이며 보편적 하한이 아니다. 실제 후보는 초기잔량·시간 순서·출력·재충전·종단 잔량을 포함한 제약으로 결정한다. 모든 교정일에 제약을 만족하는 후보 중 (kWh,kW) 오름차순 첫 후보를 선택한다. 모두 실패하면 “후보 범위 내 실행 불가”다. 시험용 후보표를 제품 규격이나 전역 최적 용량으로 표현하지 않는다.

### 실제 관측 부하에 계획 재현

동일한 사전 선정 용량으로 forecast/oracle을 비교한다. 예측 실패도 선정 용량은 유지하고 운전은 미적용 상태로 남겨 비교 대상을 숨기지 않는다. 후보 자체가 없으면 0용량·실패 행을 남긴다.

확정 계획을 실제 부하에 재현하되 방전은 실제 부하와 SOC로 제한한다. 조정량, 최대 초과 kW, 초과 시간·kWh, ESS 미적용 초과 kWh, 피크 감소 kW, SMP 비용 차이, 종단 잔량 오차를 보고한다. 종단 잔량 오차가 남으면 다음 날 자동 재설정한 다일 연속 운전 성과로 해석하지 않는다.

비용 차이 = `Σ SMP(h)·(실제 방전−실제 충전)·Δt`. 양수는 ESS 미적용 대비 감소, 음수는 증가다. 실제 전기요금·변압기 교체비·생애주기 순편익이 아니다. 열화·설치·교체·유지관리 비용은 미포함이다.

### SMP

`load_smp(path)`는 `timestamp,smp` 정규화 CSV(KST 시간 시작, 원/kWh)를 받는다. EPSIS 원본을 그대로 읽는 로더라고 주장하지 않는다. 지역 가격·단위·시각·기간·정보 공개 시점을 먼저 확인한다. 15분 자료는 네 값이 있는 시간만 평균하며 중복·비정각·결측은 거부한다. 파일 실패 또는 해당 날짜 가격 24개 부족은 피크 목적함수로 전환하고 비용은 결측이다. 과거 SMP를 사용한 결과는 사후 가격 비교이며, 전날 가격 이용 가능성이 확인되어야 운용 가능한 사전 스케줄로 볼 수 있다.

## 5. 공공성 검토표와 지도

`public_priority(results, public_evidence=None, multiplier=1.2)`는 **부하 점검 순서**를 반환한다. 기준은 증설 0대·상한 1.2배·forecast. 다른 배수 결과도 함께 보고한다.

- 계산 유효: 평가일 전체 계획 가능, 예측 신뢰 조건 충족, 종단 에너지 오차 절대값 ≤ 1e-6kWh.
- 증빙 확인: 지역별 JSON에 `status=confirmed`, `source`, `checked_on`이 모두 있어야 한다. 담당자는 공용 개방성·자가 충전 제약·대체 충전 접근성 등의 실제 근거를 검토한 뒤 입력한다. 코드가 형평성이나 주민 수혜를 자동 판정하지 않는다.
- 계산/증빙 중 하나라도 미충족: **자료 보완 후 검토**. 미확보를 0점 처리하지 않는다.
- 모두 충족하고 ESS 미적용 평균 초과 kWh>1e-6: **현장 우선 검토**. 그 외: **현 시나리오에서 초과 없음**.
- 정렬: ESS 미적용 평균 초과 kWh 내림차순 → 적용 후 잔여 초과 kWh 내림차순 → 법정동코드 오름차순. 공공 예산 배분 확정 순위가 아니다.

산출: `s8a_validation`, `s8b_scenarios`, `s8b_schedules`, `s8b_comparison`, `s9_public_review`. 기존 CSV+PNG 방식을 사용한다. CSV는 현장 작업용이며 PNG도 반출 심의 대상이다. 실제 지리 지도는 Python 자동 산출물이 아니다.

코드 마스터 CSV는 속성표다. 도형은 국토교통부 행정구역도 WFS 읍면동 레이어 `lt_c_ademd_info` 등에서 별도로 확보해 QGIS로 결합한다. 원본 기준일·좌표계·키 필드·라이선스·미매칭률을 기록한다. 8자리 법정동임을 확인한 코드만 뒤에 00을 붙여 10자리 기준코드와 대응한다. 기존 2023년 경계 중심점은 근사 입력이므로 최신 폴리곤 조인과 같다고 하지 않는다. 경계 원자료를 검증하기 전 지도 완성을 주장하지 않는다.

- [AFDC 공동주택 충전](https://afdc.energy.gov/fuels/electricity-charging-multi): 공동주택 설치 여건의 일반 배경. 국내 취약계층 수혜 추정의 근거는 아님.
- [QGIS geometry definition](https://docs.qgis.org/3.44/en/docs/user_manual/managing_data_source/opening_data.html#geometry-definition): 속성 CSV와 도형 정의 구분.
- [국토교통부 행정구역도](https://www.data.go.kr/data/15059008/openapi.do): 읍면동 WFS 제공 목록. 실제 경계 파일·분석연도 정합은 별도 확인.
- [행정표준코드](https://www.code.go.kr/stdcode/regCodeL.do): 법정동코드 조회.
- [EPSIS SMP](https://epsis.kpx.or.kr/epsisnew/selectEkmaSmpSmpChart.do?menuId=050201): 공개 가격 통계. 원본 규격과 사전 이용 가능 시점은 반입 전 확인.

이 명세는 기존 v5 지시보다 우선한다. 특히 “새 로더 불필요”, “예측 실패→실측 대체”, “방전효율만으로 용량 확정”, “CSV가 경계를 대체” 지시는 폐기한다.
