## 여섯 가지 리뷰 지적의 처리

1. **SOC를 빠뜨린 용량식**: SOC 사용 범위·효율을 포함한 참고값으로 수정. 초기잔량·시간순서·재충전·종단잔량을 검증한 이산 후보만 선택한다. “전역 최적 용량” 표현을 삭제했다.
2. **역송·동시 충방전**: 순부하 하한 0과 초과분 고정 방전/비첨두 충전 정책을 명시하고 실제 제약 검증을 추가했다.
3. **공공 우선순위 재현성**: 기준 시나리오·예측 신뢰 조건·증빙 확인 상태·분류·동률 정렬을 명세화했다. 형평성 미확보 지역은 자료 보완 대상이며 0점이 아니다.
4. **충전 스케줄링 과장**: 이번 구현은 ESS 미적용/적용 비교다. 차량 수요 시간 이동은 출차·요구 충전량·설비 조건 확보 후 비교할 후속 범위로 한정했다.
5. **코드 CSV와 경계 혼동**: 코드 마스터와 WFS/SHP 도형을 분리하고 국토교통부 공식 경계 출처, 코드·기준일·좌표계 검증 절차를 제시했다.
6. **주간 시차 단위 모호성**: 날짜 d에서 7w일을 빼고 같은 h시각을 읽도록 명시·구현했다. 기존 월별 일평균을 일별 이력으로 복제하지 않는다.

추가로 평가 이후 자료로 대상·상한·용량을 정하는 누수를 방지하고, 예측 실패를 실측으로 덮어쓰지 않으며, 활성화 시점(002)과 전력 부하(001)를 분리했다. 기존 저CATE 투자 후순위 문구도 제거했다.

## 아직 원자료가 필요한 항목

- DSZ 목록은 확인했으나 상세 미리보기가 열리지 않아 일자·시각·단위·기간·포괄 범위는 확인 전이다. CSV가 월 집계만 제공되면 day-ahead 부분은 보류한다.
- 공식 공휴일 설정과 SMP 원본 규격·가격 지역·사전 공개 시점은 현장 적용 전에 확인한다. 기본 mock은 공휴일 미보정이며 가격은 합성이다.
- 실제 경계 도형을 내려받아 기준일·코드 개편·공간 조인까지 검증한 결과는 없다. Python 표·차트를 실제 지리 지도 완성이라고 부르지 않는다.
- 공공성 증빙·자가 충전 제약·접근성·변압기 접속관계·정격·전체 부하는 미확보다. mock 검토표 15지역은 모두 증빙 보완 상태다. 증설 0대 기준에서 초과가 없으면 억지로 투자 순위를 만들지 않는다.
- 생애주기 비용, 차량 수요 시간 이동, 다일 연속 운전은 후속 검증이다. 정전 방지·변압기 교체비 절감액을 신청서 성과로 쓰지 않는다.
